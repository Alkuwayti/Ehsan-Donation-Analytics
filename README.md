# Ehsan Donation Analytics | Power BI

## Project Overview
An interactive Power BI dashboard developed using open data to analyze donation patterns, donor demographics, and contribution trends.

## Project Workflow
• Collected and cleaned donation data using Power Query.
• Investigated data discrepancies and sought clarification from the organization.
• Developed DAX measures and structured data for analysis.
• Designed a four-page interactive dashboard with KPIs, charts, and filters.
• Identified donation trends and insights to support data-driven decision-making.

## Dashboard Pages
• Category & Demographic Analysis
• Donation Patterns
• Contribution Intensity
• Insights

## Tools & Skills
Power BI | Power Query | DAX | Data Cleaning | Data Modeling | Data Visualization
